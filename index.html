About

The code enforces the rules. The AI provides the judgement.

I'm Adrie. I founded AESKA Lab Solution, a small Malaysian studio that builds consumer products and AI automation, and I'm a Full Stack Developer Intern at MoneyMax while I finish a Computer Science degree in Big Data at UiTM.

I started in applied data work, scraping marketplaces, matching messy listings and training models. PricePulse taught me that a model can hit 76% accuracy without ever predicting a change, so now I decide how to measure something before I build it. I moved into products because I wanted that kind of care in software people use every day.

I build web apps end to end, from the database and API to the interface, plus AI agents and the infrastructure they run on. I build them to fail closed, measure everything, and keep them simple.
